# Picasso Image Library

The root `Images` folder keeps the original uploaded files untouched. The folders below contain copied references grouped for website use, so one image can appear in more than one category.

## Folders

- `00-selected-website`: Best images for immediate use across the website. Use these first for homepage hero proof, product category cards, and premium gallery sections.
- `01-rigid-boxes`: Magnetic boxes, drawer boxes, hinged boxes, jewelry boxes, inserts, trays, and luxury rigid box sets. Use on `/rigid-boxes`, hero animation proof panels, rigid box product cards, and finish/process sections.
- `02-paper-bags`: Kraft bags, rope handle bags, flat handle bags, D-cut bags, retail bags, QSR/food bags, and lifestyle bag shots. Use on `/paper-bags`, product category cards, industries sections, and brochure gallery.
- `03-process-dielines`: Folding steps, dielines, inserts, tray/structure views, and production/service diagrams. Use for process sections, material education, and “how packaging is built” animations.
- `04-finishes-details`: Close-ups or images that show foil, embossing, inserts, premium handles, ribbons, and specialty details. Use for Finishes & Materials.
- `05-lifestyle-group-shots`: Multi-product or environment shots. Use for homepage proof sections, industry cards, credibility sections, and social/communication assets.
- `99-reference-low-priority`: Images that may be useful as reference but should be used sparingly because they are less premium, more generic, lower resolution, or duplicated.

## Website Usage Plan

- Hero: use original animation with selected rigid box proof images from `00-selected-website` and `01-rigid-boxes`.
- Product Categories: use one premium paper bag image, one premium rigid box image, and one white/custom packaging set.
- Rigid Boxes page: build a stronger gallery from `01-rigid-boxes`, especially magnetic, drawer, jewelry, and insert formats.
- Paper Bags page: use `02-paper-bags` for handle types, retail applications, food/QSR, and kraft sustainability visuals.
- Finishes page: use `04-finishes-details` for foil, embossing, insert, ribbon, and premium handle details.
- Process page/sections: use `03-process-dielines` to explain folding, structure recommendation, sampling, inserts, and finishing.
- Brand/social collateral: use `05-lifestyle-group-shots` for broad visual proof without making the website feel like a raw catalog.

## Adding More Images

Add new files to the root `Images` folder first. Then copy them into the best category folders above. For website deployment, convert chosen images to optimized `.webp` files under `public/products` before referencing them in code.
